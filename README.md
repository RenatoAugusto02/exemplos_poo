# Exemplos POO

Repositório com exemplos práticos de Programação Orientada a Objetos (POO) em PHP.

## 📖 Conteúdo

- Conceitos fundamentais de POO
- Classes e objetos
- Herança
- Polimorfismo
- Encapsulamento
- Exemplos práticos em PHP

## 🎯 Objetivos

- Aprender os pilares da POO
- Entender como implementar classes e objetos
- Praticar relações entre objetos
- Desenvolver habilidades de design orientado a objetos

## 💻 Linguagem

- PHP

## 📚 Tópicos Abordados

- Definição de classes
- Propriedades e métodos
- Modificadores de acesso (public, private, protected)
- Herança e interfaces
- Polimorfismo
- Abstração
- Encapsulamento de dados

## 🚀 Como Usar

1. Clone o repositório
2. Explore os exemplos de código em PHP
3. Estude cada conceito de POO
4. Adapte os exemplos para seus projetos

## 📝 Estrutura

Cada arquivo contém exemplos específicos de conceitos de POO, facilitando o aprendizado incremental.
